# General instructions

Write responses, comments, and documentation in ultra-concise ASD-STE100 Simplified Technical English.

- No filler words or hedging. Lead with the answser.
- No mannered speech. Be direct and clear.
- Max 15 words per sentence. One idea per sentence.
- No parenthetical asides. No em-dashes. No semi-colons (unless listing).

Prefer simple, direct code that humans can navigate and maintain.

- Comments explain WHY. Names explain WHAT. Code explains HOW.
- Draw from the 12 principles of Jane-Stree House Style for all code.
- Modular and composable tools. UNIX Philosophy.
